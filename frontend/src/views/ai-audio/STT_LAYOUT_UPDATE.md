# 语音转文字页面布局优化

## 🎨 新布局设计

### 左右两栏布局

```
┌─────────────────────────────────────────────────────────────────┐
│ 语音转文字                                                       │
├────────────────────────────┬────────────────────────────────────┤
│ 【左侧：上传和操作区域】    │ 【右侧：识别结果区域】              │
├────────────────────────────┼────────────────────────────────────┤
│ ┌────────────────────────┐ │ ┌──────────────────────────────┐  │
│ │       🎵              │ │ │ 识别结果 [✓ 完成]           │  │
│ │ 点击或拖拽上传音频     │ │ ├──────────────────────────────┤  │
│ │ 支持 MP3, WAV 格式     │ │ │ ┌────────────────────────┐  │  │
│ └────────────────────────┘ │ │ │ 这是识别出来的文字     │  │  │
│                            │ │ │ 内容，支持流式显示... │  │  │
│ ┌────────────────────────┐ │ │ │                        │  │  │
│ │ 音频预览              │ │ │ │ （自动换行，可滚动）   │  │  │
│ │ [━━━━━ 播放 ━━━━━]   │ │ │ └────────────────────────┘  │  │
│ └────────────────────────┘ │ │                              │  │
│                            │ │      [📋 复制文本]           │  │
│      [开始识别]            │ │ └──────────────────────────────┘  │
└────────────────────────────┴────────────────────────────────────┘
```

## ✅ 实现的功能

### 1. 左右分栏布局
```css
.stt-content-wrapper {
  display: grid;
  grid-template-columns: 1fr 1fr;  /* 左右各占 50% */
  gap: 2rem;
  align-items: start;
}
```

### 2. 左侧面板（上传区域）
- ✅ 音频上传区域
- ✅ 音频预览播放器 ⭐
- ✅ 开始识别按钮

```vue
<div class="stt-left-panel">
  <!-- 上传区域 -->
  <div class="upload-section">...</div>
  
  <!-- 音频预览 -->
  <div class="audio-preview" v-if="selectedAudio">
    <audio controls>...</audio>
  </div>
  
  <!-- 识别按钮 -->
  <div class="action-section">
    <button>开始识别</button>
  </div>
</div>
```

### 3. 右侧面板（识别结果）
- ✅ 实时显示识别文字
- ✅ 状态徽章（识别中/完成）
- ✅ 复制文本按钮
- ✅ 空状态占位符

```vue
<div class="stt-right-panel">
  <!-- 有结果时 -->
  <div v-if="sttResult">
    <h3>识别结果 [✓ 完成]</h3>
    <div class="result-text">识别的文字...</div>
    <button>📋 复制文本</button>
  </div>
  
  <!-- 无结果时 -->
  <div v-else class="empty-result-placeholder">
    <div>📝</div>
    <p>识别结果将在此处显示</p>
  </div>
</div>
```

## 🎯 优化点

### UI 改进
- ✅ **删除置信度显示** - 简化界面
- ✅ **删除时长显示** - 简化界面
- ✅ **新增音频预览** - 可试听上传的音频
- ✅ **左右分栏** - 更直观的操作流程
- ✅ **空状态提示** - 友好的引导

### 交互优化
- ✅ 上传后立即可试听
- ✅ 识别结果实时显示在右侧
- ✅ 复制按钮居中显示
- ✅ 结果区域自动滚动

### 响应式设计
- **桌面端（> 1024px）**: 左右两栏
- **平板端（< 1024px）**: 垂直布局
- **移动端（< 768px）**: 单列布局

## 📐 尺寸规格

### 左侧面板
- 宽度：50%（Grid 1fr）
- 内容：垂直排列

### 右侧面板
- 宽度：50%（Grid 1fr）
- 最小高度：400px
- 识别结果最小高度：350px

### 结果文本框
- 最小高度：250px
- 可滚动（overflow-y: auto）
- 自动换行（pre-wrap）

## 🎨 视觉层次

```
优先级1: 左侧上传区域（用户第一步操作）
    ↓
优先级2: 音频预览播放器（验证文件）
    ↓
优先级3: 开始识别按钮（触发识别）
    ↓
优先级4: 右侧结果显示（查看结果）
    ↓
优先级5: 复制文本按钮（保存结果）
```

### 音频预览
```typescript
// 创建 Blob URL
selectedAudioUrl.value = URL.createObjectURL(file)

// 清理旧 URL
URL.revokeObjectURL(selectedAudioUrl.value)

// 组件卸载时清理
onUnmounted(() => {
  URL.revokeObjectURL(selectedAudioUrl.value)
})
```
