## 🔧 技术实现

### 默认配置
```typescript
const textToVideoForm = reactive<TextToVideoRequest>({
  prompt: '',
  model: 'wan2.5-t2v-preview',        // 固定模型
  resolution: '1280*720',              // 默认 720P
  duration: 5,                         // 默认 5秒
  fps: 24,                             // 固定 24fps
  seed: Math.floor(Math.random() * 2147483647)  // 随机种子
})
```

### 随机种子功能
```typescript
// 生成随机种子
const randomizeSeed = () => {
  textToVideoForm.seed = Math.floor(Math.random() * 2147483647)
  toast.info(`已生成随机种子: ${textToVideoForm.seed}`)
}
```

### 种子输入框
```vue
<input 
  type="number" 
  v-model.number="textToVideoForm.seed" 
  min="0" 
  max="2147483647"
  placeholder="0 - 2147483647"
>
<button @click="randomizeSeed">🎲 随机</button>
```

## 🌟 新增特性

### 随机种子功能

**作用**：
- 控制视频生成的随机性
- 相同种子 + 相同参数 = 相似结果
- 便于复现特定效果

**使用方式**：
1. 自动生成：页面加载时随机生成
2. 手动输入：输入特定种子值
3. 一键随机：点击"🎲 随机"按钮

**范围限制**：
```
最小值：0
最大值：2,147,483,647（2^31 - 1）
```
