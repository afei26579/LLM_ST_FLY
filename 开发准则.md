## 通用规则

### 开发环境

1. **操作系统**: Windows / Linux / macOS
2. **Python**: 3.10+
3. **Node.js**: 16+
4. **包管理器**: 
   - Python: pip
   - Node.js: pnpm（推荐）/ npm

### 基本原则

1. **没有明确要求时，不要主动编写 .md 文档**
2. **Windows 系统注意事项**:
   - 终端命令使用 PowerShell 或 CMD
   - 路径使用反斜杠 `\` 或正斜杠 `/`（推荐）
   - 虚拟环境激活：`venv\Scripts\activate`
3. **执行后端命令前，必须先激活虚拟环境**
4. **遵循项目已有的代码风格和架构模式**
5. **参考已完成的功能来实现新功能**

from django.db import models
from django.contrib.auth.models import AbstractUser

class User(AbstractUser):

from core.views import StandardModelViewSet
from core.response import StandardResponse
from rest_framework.decorators import action

class UserViewSet(StandardModelViewSet):
    """用户管理视图集"""
    queryset = User.objects.all()

### 序列化器规范

```python
from rest_framework import serializers
from .models import User

class UserSerializer(serializers.ModelSerializer):
    """用户序列化器"""
    
    # 只读字段
    id = serializers.IntegerField(read_only=True)
    created_at = serializers.DateTimeField(read_only=True)
    
    # 自定义字段
    avatar_url = serializers.SerializerMethodField()
    
    class Meta:
        model = User
        fields = ['id', 'username', 'email', 'avatar', 'avatar_url', 'created_at']
        extra_kwargs = {
            'password': {'write_only': True},
        }
    
    def get_avatar_url(self, obj):
        """获取头像完整URL"""
        if obj.avatar:
            request = self.context.get('request')
            return request.build_absolute_uri(obj.avatar.url)
        return None
    
    def validate_email(self, value):
        """验证邮箱"""
        if User.objects.filter(email=value).exists():
            raise serializers.ValidationError('邮箱已被使用')
        return value
```

**要点**：
1. 使用 `ModelSerializer` 简化序列化器定义
2. 设置只读字段：`read_only=True`
3. 设置只写字段：`write_only=True`
4. 使用 `SerializerMethodField` 定义计算字段
5. 使用 `validate_字段名` 方法验证单个字段
6. 使用 `validate` 方法进行跨字段验证

### 业务逻辑规范

业务逻辑应该放在 `services.py` 中，而不是直接写在视图里。

```python
# services.py
from typing import Dict, Any
import logging

logger = logging.getLogger(__name__)

class UserService:
    """用户业务逻辑服务"""
    
    @staticmethod
    def create_user(user_data: Dict[str, Any]) -> User:
        """创建用户
        
        Args:
            user_data: 用户数据字典
            
        Returns:
            User: 创建的用户对象
            
        Raises:
            ValidationError: 数据验证失败
        """
        try:
            # 验证数据
            if User.objects.filter(username=user_data['username']).exists():
                raise ValidationError({'username': ['用户名已存在']})
            
            # 创建用户
            user = User.objects.create_user(**user_data)
            logger.info(f"用户创建成功: {user.username}")
            return user
            
        except Exception as e:
            logger.error(f"创建用户失败: {e}")
            raise
```

**要点**：
1. 使用类组织相关的业务逻辑
2. 添加类型注解
3. 添加文档字符串说明参数和返回值
4. 使用日志记录关键操作
5. 适当的异常处理

### API 调用规范

#### 统一使用 API 服务

```typescript
// services/api.ts
import axios from 'axios'

class ApiService {
  private instance: AxiosInstance
  
  constructor() {
    this.instance = axios.create({
      baseURL: 'http://localhost:8000/api/v1/',
      timeout: 15000,
    })
    
    // 请求拦截器
    this.instance.interceptors.request.use(
      (config) => {
        const token = localStorage.getItem('token')
        if (token) {
          config.headers['Authorization'] = `Bearer ${token}`
        }
        return config
      }
    )
    
    // 响应拦截器
    this.instance.interceptors.response.use(
      (response) => response,
      (error) => {
        if (error.response?.status === 401) {
          // 处理未授权
          localStorage.removeItem('token')
          window.location.href = '/login'
        }
        return Promise.reject(error)
      }
    )
  }
  
  async getUserList(): Promise<ApiResponse<PaginatedUserList>> {
    const response = await this.instance.get('auth/user-management/')
    return response.data
  }
}

export const apiService = new ApiService()
```

### 状态管理规范

```typescript
// stores/auth.ts
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

export const useAuthStore = defineStore('auth', () => {
  // State
  const user = ref<User | null>(null)
  const token = ref<string | null>(null)
  
  // Getters
  const isLoggedIn = computed(() => !!token.value)
  const userName = computed(() => user.value?.username || '')
  
  // Actions
  const login = async (credentials: LoginRequest) => {
    try {
      const response = await apiService.login(credentials)
      if (response.code === 200) {
        token.value = response.data.token.access
        user.value = response.data.user
        localStorage.setItem('token', token.value)
        return true
      }
      return false
    } catch (error) {
      console.error('登录失败:', error)
      return false
    }
  }
  
  const logout = () => {
    token.value = null
    user.value = null
    localStorage.removeItem('token')
  }
  
  return {
    user,
    token,
    isLoggedIn,
    userName,
    login,
    logout
  }
})
```

## API 接口规范

### 统一响应格式

所有 API 接口必须遵循统一的响应格式：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {},
  "timestamp": "2025-01-08T19:00:00Z",
  "request_id": "uuid-string"
}
```

### 后端实现

```python
from core.response import StandardResponse
from core.views import StandardModelViewSet

class UserViewSet(StandardModelViewSet):
    queryset = User.objects.all()
    serializer_class = UserSerializer
    
    def create(self, request):
        serializer = self.get_serializer(data=request.data)
        serializer.is_valid(raise_exception=True)
        user = serializer.save()
        
        return StandardResponse.success(
            data=serializer.data,
            message="用户创建成功",
            code=201,
            request_id=getattr(request, 'request_id', None)
        )
```

### 前端处理

```typescript
interface ApiResponse<T = any> {
  code: number
  message: string
  data: T
  timestamp: string
  request_id: string
}

const handleResponse = async () => {
  const response = await apiService.getUserList()
  
  if (response.code === 200) {
    // 成功处理
    return response.data
  } else {
    // 错误处理
    toast.error(response.message)
    throw new Error(response.message)
  }
}
```

### 状态码使用

- **200**: 成功
- **201**: 创建成功
- **400**: 客户端错误（参数错误等）
- **401**: 未授权
- **403**: 禁止访问
- **404**: 资源不存在
- **500**: 服务器内部错误

详细说明请参考：[backend/docs/api_response_format.md](backend/docs/api_response_format.md)

## 文档规范

### 代码注释

```python
def calculate_total_price(items: List[Dict], discount: float = 0) -> float:
    """计算订单总价
    
    Args:
        items: 商品列表，每个商品包含 price 和 quantity
        discount: 折扣，0-1 之间的浮点数，默认为 0
    
    Returns:
        float: 折扣后的总价
    
    Raises:
        ValueError: 当 discount 不在 0-1 范围内时
    
    Examples:
        >>> items = [{'price': 10, 'quantity': 2}, {'price': 20, 'quantity': 1}]
        >>> calculate_total_price(items, 0.1)
        36.0
    """
    if not 0 <= discount <= 1:
        raise ValueError("折扣必须在 0-1 之间")
    
    total = sum(item['price'] * item['quantity'] for item in items)
    return total * (1 - discount)
```
