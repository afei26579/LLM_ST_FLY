# 流式聊天API测试工具

## 📝 说明

这是一个用于测试流式聊天API的Python脚本，可以在命令行中实时查看AI的流式输出效果。

## 🚀 快速开始

### 1. 确保后端服务运行

```bash
# 在项目根目录
cd backend
python manage.py runserver
```

### 2. 运行测试脚本

```bash
# 方式1：直接运行
python backend/chat/ai-chat/test.py

# 方式2：进入目录后运行
cd backend/chat/ai-chat
python test.py
```

### 3. 输入登录信息

脚本会提示输入用户名和密码（默认都是 `admin`），然后自动获取认证token。

### 4. 选择测试场景

```
请选择测试场景:
  1. 简单问答 (默认)
  2. 深度思考模式
  3. 联网搜索模式
  4. 自定义问题
  0. 退出
```

## 📊 测试场景说明

### 1. 简单问答
- 问题：你好，请介绍一下你自己
- 功能：测试基本的流式输出

### 2. 深度思考模式
- 问题：请深入分析一下人工智能的未来发展趋势
- 功能：测试启用深度思考的流式输出
- 特点：会先显示思考过程，然后显示回答

### 3. 联网搜索模式
- 问题：今天杭州的天气怎么样
- 功能：测试联网搜索的流式输出

### 4. 自定义问题
- 可以输入任意问题
- 可以选择是否启用深度思考和联网搜索

## 🔧 配置说明

### 修改API地址

如果后端运行在其他地址，修改脚本中的配置：

```python
API_BASE_URL = "http://localhost:8000"  # 修改为你的后端地址
```

### 使用固定Token

如果不想每次都登录，可以手动设置token：

```python
TOKEN = "your_actual_token_here"  # 替换为真实token
```

获取token的方法：
1. 在浏览器登录系统
2. 打开开发者工具 (F12)
3. 在本地存储 (localStorage) 中查找 `token`
4. 复制token值到脚本中

## 🐛 常见问题

### 1. 连接被拒绝
**问题**：`ConnectionRefusedError` 或 `Connection refused`

**解决**：
- 检查后端服务是否正在运行
- 确认端口号是否正确（默认8000）

### 2. 认证失败
**问题**：`401 Unauthorized`

**解决**：
- 检查用户名和密码是否正确
- 确认用户账户是否激活
- 尝试重新获取token

### 3. 请求超时
**问题**：`Timeout` 错误

**解决**：
- 检查网络连接
- 增加超时时间：修改脚本中的 `timeout=60` 为更大的值
- 检查后端API是否正常响应

### 4. 看不到流式效果
**问题**：内容一次性全部显示

**解决**：
- 确认使用的是 `stream=True`
- 检查后端是否正确返回SSE格式
- 查看后端日志是否有错误
